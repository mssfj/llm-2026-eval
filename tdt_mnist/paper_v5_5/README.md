# TDT-v5.5 PDF生成・検証

成果物：`doc/TDT-v5.5_離散状態遷移学習理論.pdf`（186ページ）。追加21ページ＋変更せず継承したv5.4の165ページ。

- 1〜8ページ：固定条件、CPU fastの途中終了、CPU単独最適化、GPU短期比較、E17a全長再現。
- 9〜11ページ：区間時間、最終精度、CUDA Graph処理フローのベクトル図。
- 12〜19ページ：CUDA Graph処理詳細G1〜G8。CPU/GPU配置、RNG先読み、候補別BMM、固定バッファ、捕捉・再生、転送・重み同期、CPU判定、数値差と検証。
- 20〜21ページ：全長時間内訳、監査・添付資料。
- 22ページ以降：v5.4全文と旧版の原記録。

`doc/TDT-v5.5_追加実験データ.zip`はPDFにも埋め込み済み。集計、設定、監査、事前登録、実行時ソース、停止記録、本文原稿と生成スクリプトを収録。大容量の逐区間CSV・NPY・PTは元のresultsディレクトリを参照。

生成（リポジトリルートから）：

```sh
uv run --offline --with pymupdf --with reportlab python tdt_mnist/paper_v5_5/build_pdf.py
```

これは資料生成のみで、学習・test再評価をしない。既存結果252ファイルのハッシュ、GPU評価器の実行時ソース一致、3 seed精度集計、旧版全ページの抽出テキスト・描画画素、全添付データ、追加部のページ外テキストがないことを検査する。結果は`pdf_validation.json`。

追加21ページのプレビュー全体と、精度図・処理図・テンソル表・Graph捕捉説明の拡大を目視確認した。原稿は`cuda_graph_details.md`、総括は`../ENGINE_OPTIMIZATION_SUMMARY.md`、抽出用追加本文は`TDT-v5.5_追加本文.txt`。PDF内のしおりから各節へ移動できる。
